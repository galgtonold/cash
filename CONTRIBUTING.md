# Contributing to Cash

Thanks for your interest in contributing. The contributor guide is
[docs/contributing.md](docs/contributing.md), also published at
<https://cash-lib.readthedocs.io/en/stable/contributing/>. It covers setup,
the project layout, running and writing tests, and the pull request process.

To get started:

```bash
git clone https://github.com/galgtonold/cash.git
cd cash
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -e ".[dev]"
```
